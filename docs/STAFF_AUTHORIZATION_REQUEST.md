# Staff authorization request

We request a bounded test of the official `Voice Rooms` bot in one staff-approved temporary voice channel.

Requested operations:

- Install the bot with the presence-only permission profile.
- Record the exact guild, voice-channel, and voice-chat IDs through `/voice-admin authorize-target`.
- Allow join, leave, status, redacted diagnostics, and one plain-text relay during an agreed window.
- Observe the third-party room's normal deletion behavior without synthetic activity.

The bot will not invoke another bot, automate a user account, record or receive audio, send audio, modify the temporary channel, change ownership or permissions, or attempt to defeat inactivity rules.

Please supply the approving staff member, approval reference, time window, exact target IDs, and removal requirement. If the room needs a documented persistent or exempt mode, staff must configure or explicitly authorize that mode.
